# UI/UX Pro Max - Community Edition

## Cuándo Activar esta Skill
- Cuando el usuario solicite la maquetación de una interfaz, landing page o dashboard.
- Al refactorizar estilos CSS, Tailwind, componentes de React, Vue o Flutter.
- Cuando se requiera validar el contraste de color o la accesibilidad (WCAG).

## Árbol de Decisión de Diseño (Flujo del Agente)
1. **Analizar la industria:** ¿Es Fintech (confianza/limpieza), Gaming (oscuro/experimental) o SaaS (productividad/escala)? Aplica la psicología del color correspondiente.
2. **Establecer la escala:** Define tokens para spacing (4px, 8px, 16px, 24px, 32px), jerarquía tipográfica base y radios de bordes (bento grid, esquinas suavizadas).
3. **Escribir Código Limpio:** Implementa siempre estados interactivos (`hover:`, `focus-visible:`, `disabled:`) y transiciones fluidas.

## Checklist de Verificación Obligatoria
- [ ] ¿El texto es legible sobre el fondo elegido (Contraste mínimo 4.5:1)?
- [ ] ¿Los botones e inputs tienen un tamaño táctil mínimo de 44x44px?
- [ ] ¿Hay suficiente espacio en blanco para evitar la saturación cognitiva?
- [ ] ¿Se añadieron estados de carga (`loading`) y pantallas vacías (`empty states`)?
